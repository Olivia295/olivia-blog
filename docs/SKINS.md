# 皮肤维护

每套皮肤的源文件集中在 `src/skins/<id>/`。内容与布局共用；外观、装饰和专属交互由皮肤管理。

## 修改现有皮肤

| 文件                                 | 用途                                                          |
| ------------------------------------ | ------------------------------------------------------------- |
| `skin.ts`                            | 稳定标识、中文/英文名称、浅色和深色主配色                     |
| `styles.css`                         | 样式入口、基础字体、界面外观；可继续拆分目录内的 CSS          |
| `components.css`                     | 页头、列表、关于页、音乐播放器等共用组件的皮肤外观            |
| `copy.ts`                            | 皮肤专属界面文案；不会改写作者的介绍或文章                    |
| `Decorations.astro`                  | 可选：在共用页面的挂载位置提供装饰                            |
| `behavior.ts`                        | 可选：导出 `activate()`，返回关闭弹窗、清理监听和观察器的函数 |
| `components/`、`scripts/`、`assets/` | 可选：这套皮肤独有的组件、行为和资源                          |

飞船版另有 `cabin.css`（飞船外观）与 `motion.css`（动画）。简洁版不导入飞船的样式或行为。

颜色统一在各自的 `skin.ts` 中修改。旧站点配置中的 `colors` 仍可被配置解析器读取，但不再覆盖皮肤配色；这避免一处全局颜色改动影响所有皮肤。构建生成的应用图标元信息采用站点默认皮肤的配色。

## 默认皮肤与访客选择

在内容仓库的 `site/site.json` 设置：

```json
"defaultSkin": "spaceship"
```

也可设置为 `minimal`。沿用现有 `npm run content:sync` 同步流程，再重启开发服务或重新构建发布。同步方向始终是内容仓库到博客，访客操作不会写回内容仓库。

关于页最下方提供“跟随站点默认”和所有已登记皮肤。个人选择保存在浏览器的 `blog-skin` 中，优先于站点默认。选择“跟随站点默认”会清除个人覆盖。失效的个人选择回退到站点默认；配置文件中的未知皮肤标识会报告配置错误。

明暗模式仍使用原有 `theme` 偏好，与皮肤独立。无 JavaScript 时展示站点默认皮肤；存储不可用时仍可在当前页面切换。

## 新增第三套皮肤

1. 新增 `src/skins/<id>/skin.ts` 与 `styles.css`，标识与目录同名；可以参考简洁版的目录。
2. 在 `src/skins/registry.ts` 导入并登记其元信息。这是唯一需要修改的公共登记位置。
3. 样式限定在 `html[data-skin="<id>"]` 下。声明独立的字体和外观值；动画名称使用自己的皮肤前缀。
4. 如需装饰，新增 `Decorations.astro`。可用 `position` 为 `surround`、`content-start`、`page-end`、`home-background`、`home-eyebrow`、`home-status`、`home-controls`；同时接收 `lang` 和 `home`。
5. 如需交互，新增 `behavior.ts`。仅激活的皮肤会加载该模块；退出时必须停止定时器、监听、观察器并关闭自己的弹窗，不清除用户偏好。

下拉选项自动从登记清单生成。样式、装饰与行为按目录约定接入，不需要修改每个页面，也不需要修改其他皮肤。所有装饰片段在构建时生成，内容只渲染一次；未激活的片段不显示且不可聚焦。

`src/styles/layout.css` 和公共组件内保留页面宽度、栏目排列、响应式布局及功能状态。公共样式中的语义变量与第三方内容渲染接口由皮肤赋值；改变整体布局属于独立的布局修改。

## 简单检查

```sh
node --experimental-strip-types --test tests/unit/skins.test.mjs
node node_modules/astro/bin/astro.mjs check
```

启动开发服务或生产预览后运行（默认地址为 `http://127.0.0.1:4325`）：

```sh
SKIN_TEST_URL=http://127.0.0.1:4325 node scripts/test-skins.mjs
```

该检查不创建内容样例，覆盖选择、键盘、持久化、语言、明暗模式、桌面/手机主要页面、图片/搜索弹窗、登船退出清理和存储不可用。截图默认放在系统临时目录，可用 `SKIN_TEST_OUTPUT` 指定输出目录。

`olivia-blog-original` 仅作视觉参照，不参与构建，不应修改。
