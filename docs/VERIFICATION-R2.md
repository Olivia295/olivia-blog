每个阶段通过后再进入下一阶段。发现并修复的失败包括：测试资料日期格式、从顶部重新登船后的键盘焦点冲突、代码格式与导入顺序。最终动效截图检查后降低首页动态层亮度，避免飞船经过时削弱标题对比度，并再次运行完整测试。

原先的混排时间线 UI 断言按用户确认的新规格更新为短记／文章独立计数、日期排序、双栏对齐和手机顺序；保留日期单元测试、相册入口及其他适用测试。没有删除或跳过测试，也没有降低验收标准让失败通过。

## 独立模板

在全新的临时目录复制模板、实际执行 `npm ci` 并构建，确认：无相邻内容源时使用明确标识的中性示例；默认素材与搜索存在；四种宽度可浏览；文章链接相册、照片浏览器可操作；另一位作者可更换名字、配色、纵向图片、数量、动效开关；内容不足／空栏目／删除图片／切换源没有旧内容残留；示例及空外壳不泄漏个人资料。

## 验证边界

使用本机 Chromium 自动化、键盘操作、触摸事件与截图核查，没有声称在实体手机或所有浏览器上做过验证。WCAG AA 自动扫描覆盖明暗主题及主要页面，另有键盘、焦点、触摸尺寸和无脚本验证；这不等同于完整辅助技术认证。

离屏暂停使用实际滚动与交叉观察器验证；后台可见性事件采用确定性的模拟测试。系统减少动画由浏览器媒体仿真验证。生产预览另外将实际文本字号及行高加倍，核对手机页面没有横向溢出，并保存截图。

加载性能是本机实验室测量，不代表真实网络或线上用户指标，未进行线上 INP 统计。最新数据保存在 `artifacts/final/production-metrics.json`。
