# 私人飞船 · 第三轮开发与验收记录

验证日期：2026-09-11。已按确认的六阶段方案完成。本轮修改网站与独立内容目录，没有执行线上发布。

## 已完成

1. 搜索在电脑导航中紧邻 Home 左侧，手机维持原布局；删除 Cabin control。暂停／恢复按钮全站左下角悬浮，重新登船仅在首页底部。模态窗口打开时隐藏悬浮按钮。
2. 文章删除 tags，统一使用双语 series。冷冰／冻冰合并，补充 Nexus Codex 英译，使用稳定 ID 筛选，支持旧名称、旧标签链接和跨语言保留筛选。示例内容与编辑说明同步更新。
3. 非首页正文及详情页共用 1000px 外框与约 24px 舷窗间距。导航半透明和局部渐隐统一覆盖所有页面，包括首页最近分享区域；渐隐装饰不参与浏览器滚动锚定，返回位置正常恢复。
4. 增加四种飞船轮廓、五种配色及小编队；三种大小／颜色不同的行星，其中一种带环。错峰慢行，阅读页面减弱动效；暂停、离屏、后台和系统减少动画均生效。
5. 舷窗上方空带缩小为结构边缘；删除双语页脚寄语，版权位于独立分隔线下方。浅色版权文字对比度已修正，手机预留悬浮按钮空间。
6. 完成实际页面检查、内容接入与模板启动验证。

## 最终验证

- 20 项单元测试通过。
- 61 项浏览器测试全部通过，失败 0、跳过 0、重试 0。
- 17 类独立模板检查通过：全新安装、示例构建、替换站主和配色、仅短记内容源、示例／个人资料隔离及空模板。
- 代码检查通过：Astro 0 错误／警告／提示；Biome 0 错误，82 条非阻断风格警告和 4 条信息，未关闭检查规则。
- 正式构建与搜索索引通过，共 240 个页面。正式输出没有测试长文、测试短记或测试音轨。
- 两个目录的差异格式检查通过；首页原始图片、同步图片和正式构建图片的 SHA-256 一致。

测试保持原有有效覆盖，涉及已删除菜单的测试改为验证新的悬浮入口与首页重播；新增双语系列、旧链接、统一间距、窗景和页脚验证。修复了真实旧链接跳转、浅色页脚对比度、渐隐层影响返回位置的问题。动画暂停测试等待浏览器完成暂停后，再检查时钟保持不变。
