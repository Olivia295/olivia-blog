# 私人飞船：第三轮设计决定

主模式是内容阅读，配合用户要求的沉浸式船舱。沿用半现实银灰停机舱、完整的右侧个人插画和正常整页滚动。

- 电脑端搜索紧邻 Home 左侧；手机沿用原布局。移除顶部 Cabin control，重新登船仅在首页底部，动效控制全站左下角悬浮，保留偏好并尊重系统减少动画。模态窗口打开时隐藏悬浮控制。
- 文章只使用 series，中文名称仍可直接填写，中英对照集中在 site/series.json。稳定 id 用于筛选链接；旧名称和旧标签链接归入对应系列。短记标签独立保留。
- 非首页正文最大宽度 1000px，左右舷窗到正文间距 24px；文章与相册详情同样遵守。框内根据阅读、照片、目录等内容安排。
- 所有页面共用带模糊背景的半透明导航底板，接近导航的内容上边缘在 44px 窄区域渐隐和轻度虚化。
- 四种飞船轮廓、五种克制配色、单舰与小编队错峰航行；三种行星有不同尺寸和颜色，其中一种带环。窗景以慢速、低频为主，阅读页继续降低亮度、延长周期。
- 舷窗上方仅保留 18px 结构边缘。页脚有独立分隔线和不透出的底色，版权信息在线下；移除双语寄语。手机页脚额外预留悬浮按钮空间。
- 首页保留 3 条最新短记、5 篇最新文章的设置：左右面板外框等高，入口对齐；内容不足时自然展示已有条目。手机先短记、后文章。

第三轮沿用现有图片和字体，不引入新的图片或动画依赖。静态设计预览保留作上一轮外观参考，实际第三轮效果以网站页面为准。
