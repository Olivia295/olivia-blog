有时候，最好的路线是不急着决定下一站。

慢一点，再慢一点

我喜欢从一张照片开始回忆。不是因为它记录得完整，而是因为照片之外的声音、温度和气味，也会慢慢浮现出来。

窗外是很远的地方，窗内是可以安心坐下来的日常。桌上还摊着读到一半的书，杯子里的茶已经凉了。

探索也可以是重新发现那些熟悉的事物。

把小事留在这里

文字、照片和片刻的念头，在这里都有自己的位置。一点点收集，就有了一段可以回头看的航程。

const journey = {
  pace: "slow",
  destination: "somewhere new"
};
