## 慢一点，再慢一点

我喜欢从一张照片开始回忆。不是因为它记录得完整，而是因为照片之外的声音、温度和气味，也会慢慢浮现出来。

窗外是很远的地方，窗内是可以安心坐下来的日常。桌上还摊着读到一半的书，杯子里的茶已经凉了。

> 探索也可以是重新发现那些熟悉的事物。

## 把小事留在这里

文字、照片和片刻的念头，在这里都有自己的位置。一点点收集，就有了一段可以回头看的航程。

我把每一次散步看作一次小小的出发。有时是走进没去过的小巷，有时只是换一条回家的路。没有非得完成的清单，只有眼前刚好落下来的光。

### 路上带些什么

- 一本可以随手记事的小本子。
- 一台相机，或者愿意认真看的眼睛。
- 一点允许自己绕远的时间。

const journey = {

整理照片时，我发现那些最喜欢的画面，往往不是出发前想好的。一面墙、一扇窗、一条安静的小路，都值得再看一眼。
